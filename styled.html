Hindi LLaMA-Omni

Ask a question in spoken Hindi, hear the answer in spoken Hindi. Built on LLaMA-Omni with a Hindi LoRA adapter, a retrained speech projector, and a dataset that did not exist before.

  • Demo
  • Code
  • Model
  • Dataset
Hardware
1× A100 80 GB
Training
2 stages · 3 epochs each · ≈ 25 h stage 1
Parameters
9.02 B total · 357 M trained (LoRA r=128)
Data
110k spoken questions · 160 h used
  • Pipeline. Whisper large-v3 encodes speech, a speech projector maps it into Llama-3.1-8B-Omni, a LoRA adapter makes the model write Hindi, IndicF5 speaks the answer in a voice cloned from a 5-second clip.
  • Dataset. No spoken-Hindi instruction data existed, so I built Hindi-speech-instruct: 110,700 AI4Bharat Indic-Instruct conversations with every question synthesised to 16 kHz speech. 158 GB, CC BY 4.0.
  • Training. Joint training from the English weights was unstable, so stage 1 teaches Hindi from text (102k conversations) and stage 2 trains the projector on 49,787 spoken questions. LoRA r = 128, α = 64, lr 1e-4 with cosine decay, bf16-mixed, ≈ 29 GB per stage.
  • Results. Against the base model: IndicQA F1 34 % → 68 %, perplexity 13.2 → 7.7, MT-Bench-Hi 3.5 → 4.6 / 10, IFEval-Hi 19.6 % → 24.4 %. Gains in QA, writing and extraction; math and coding got slightly worse.

Stable Diffusion from scratch

Every module of Stable Diffusion v1.5 reimplemented in PyTorch, then loaded with the real weights to generate images.

  • Code
Model
≈ 1.07 B params loaded
Modules
CLIP · VAE · U-Net · DDPM
Latents
512² image → 4 × 64 × 64
Sampling
50 steps · CFG 7.5
  • Built. The CLIP text encoder, VAE encoder and decoder, U-Net with self- and cross-attention, time embedding, and the DDPM sampler with the original 1,000-step β schedule. Tensor shape changes are documented at every layer.
  • How. Without the compute to train it, I wrote a converter that maps the official v1.5 checkpoint onto my module names. Classifier-free guidance, image-to-image via noised latents, and a mode that returns every denoising step.

2024 · Self-directed

Fourier epicycles from any image

Upload a picture and a chain of rotating circles redraws its outline.

  • Live demo
  • Code
Pipeline
Canny → ordering → spline → FFT
Edge points
up to 2,000
Stack
FastAPI · OpenCV · SciPy · JS canvas
  • How. Canny edges are ordered into one path by nearest-neighbour traversal, smoothed with a parametric spline, encoded as z = x + iy and FFT'd. The largest N frequencies become circles: magnitude is radius, frequency is speed, phase is start angle.
  • Limits. Works on cartoons and high-contrast images, struggles on photos. A true single-stroke contour tracer would replace the ordering step.
